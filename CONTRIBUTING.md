# Contributing

Thank you for your interest in Tabby Space.

This public kit is for feedback, documentation improvements and permission
requests. Do not submit proprietary Tabby Space source code, copied assets,
private builds, API keys or copyrighted wallpaper files.

Before contributing any content, confirm that you own it or have permission to
share it. By submitting a pull request or issue, you confirm that condition.

The copyright holder decides whether a contribution is accepted and whether a
separate written agreement is needed.
