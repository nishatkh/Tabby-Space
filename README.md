# Tabby Space public kit

This is the public, GitHub-ready companion repository for Tabby Space.

It intentionally contains selected documentation, design resources and a small
extension manifest example only. The full Tabby Space extension source, release
package, private implementation, premium interactions and bundled wallpaper
assets are not included in this repository.

## What is included

- Product overview and the public feature scope
- A small set of visual design tokens for discussion and inspiration
- A minimal Chrome extension manifest example
- Contribution and security-reporting guidance

## What is not included

- The working Tabby Space dashboard and widgets
- Liquid-glass rendering implementation
- Search, settings, storage, weather and shortcut implementation
- Built extension ZIPs, credentials, private assets or copyrighted wallpapers

## Publishing to GitHub

1. Upload only this public kit — not the private Tabby Space project.
2. Keep the included `LICENSE.md` and licence notice in this README.
3. Enable GitHub Issues if you want people to request permission or report a
   security issue.

See [the public scope](docs/PUBLIC-SCOPE.md) before accepting contributions.
