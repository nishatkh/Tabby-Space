# Public scope

The GitHub repository is deliberately limited to a public project overview and
selected reusable resources.

## Public discussion topics

- New-tab dashboard product ideas
- Accessibility and browser-extension best practices
- General glass-interface design principles
- Public documentation corrections

## Private Tabby Space work

The following remain private and must not be recreated from this kit:

- Complete interface layouts, widget source and behaviour
- Apple-style liquid-glass filter implementation and tuning
- Storage/data model, settings implementation and extension packaging
- Production assets, wallpapers, icons and release archives

To use, reproduce or integrate any private Tabby Space work, obtain written
permission under the repository licence first.
